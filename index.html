⬡ Joystick-Map

Hilfe — Joystick-Map

Erste Schritte

  • Die Datei joystick-map-vX.Y.Z.html von der Releases-Seite herunterladen.
  • Datei direkt im Browser öffnen — kein Server oder Installation nötig.
  • Oben rechts den passenden Stick aus dem Dropdown wählen.

Felder bearbeiten

  • Direkt auf ein Textfeld auf der Vorlage klicken und den gewünschten Wert eingeben.
  • Die weißen Kästchen neben den Feldern zeigen die Star-Citizen-internen Eingaben und sind nicht editierbar.
  • Alle Änderungen werden automatisch im Browser gespeichert und bleiben nach dem Neustart erhalten.

Felder sperren

  • Beim Hover über ein Feld erscheint ein kleines 🔓 in der Ecke — Klick darauf sperrt das Feld.
  • Gesperrte Felder zeigen dauerhaft ein 🔒 und einen grünen Rahmen.
  • Gesperrte Felder werden beim Reset nicht geleert.
  • Erneuter Klick auf 🔒 entsperrt das Feld wieder.

Star Citizen Import

  • Auf ⬇ SC Import klicken und die eigene actionmaps.xml aus Star Citizen auswählen.
  • Die Datei liegt normalerweise unter:
    Roberts Space Industries\StarCitizen\LIVE\user\client\0\Profiles\default\actionmaps.xml
  • Joystick L und R werden automatisch erkannt (LEFT / RIGHT im Gerätenamen).
  • Schaltflächen und Achsen werden importiert.
  • Gesperrte Felder werden beim Import übersprungen.

Star Citizen Mapping-Dateien finden

  • Eigene Mappings im Spiel mit pp_rebindkeys export Name exportieren.
  • Wichtig: Auf den aktuell gespielten Kanal achten. Wer HOTFIX spielt, muss im HOTFIX-Ordner suchen; wer LIVE spielt, im LIVE-Ordner.
  • LIVE:
    Roberts Space Industries\StarCitizen\LIVE\user\client\0\controls\mappings
  • HOTFIX:
    Roberts Space Industries\StarCitizen\HOTFIX\user\client\0\controls\mappings

Buttons im Header

  • ↶ Rückgängig — macht die letzte Änderung rückgängig.
  • ↺ Reset — leert alle nicht gesperrten Felder (nach Bestätigung).

Tabs

  • Alpha L / Alpha R — linker und rechter Stick der aktuellen Vorlage.
  • Changelog — zeigt wann welches Feld zuletzt geändert wurde.
  • ? Hilfe — diese Seite.

Hinweise

  • Die Daten werden im Browser-Speicher (localStorage) abgelegt — sie bleiben solange erhalten, bis der Browser-Cache geleert wird.
  • Jeder Browser speichert seine eigenen Daten — beim Wechsel des Browsers gehen die Einträge nicht automatisch über.
