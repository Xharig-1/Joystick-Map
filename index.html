Hilfe — Joystick-Map

Erste Schritte

  • Die Datei joystick-map-vX.Y.Z.html von der Releases-Seite herunterladen.
  • Datei direkt im Browser öffnen — kein Server oder Installation nötig.
  • Oben rechts den passenden Stick aus dem Dropdown wählen.

Felder bearbeiten

  • Direkt auf ein Textfeld auf der Vorlage klicken und den gewünschten Wert eingeben.
  • Die weißen Kästchen neben den Feldern zeigen die Star-Citizen-internen Eingaben und sind nicht editierbar.
  • Alle Änderungen werden automatisch im Browser gespeichert und bleiben nach dem Neustart erhalten.

Felder sperren

  • Beim Hover über ein Feld erscheint ein kleines 🔓 in der Ecke — Klick darauf sperrt das Feld.
  • Gesperrte Felder zeigen dauerhaft ein 🔒 und einen grünen Rahmen.
  • Gesperrte Felder werden beim Reset nicht geleert.
  • Erneuter Klick auf 🔒 entsperrt das Feld wieder.

Modus-Tags (Combat / Mining / Salvage)

Jedes Feld kann mit einem oder mehreren Spielmodi markiert werden — so sieht man auf einen Blick, welche Tasten zu welcher Tätigkeit gehören. Die Zuordnung bleibt dauerhaft gespeichert.

  • Farben: ■ Combat   ■ Mining   ■ Salvage
  • Stick-Vorlage (Alpha L / R, VKB …): Über ein Feld hovern — unten links erscheinen farbige Punkte (bei bereits gesetzten Tags) oder ein leeres Kreissymbol. Klick darauf öffnet ein kleines Popup mit Checkboxen. Haken setzen oder entfernen, dann irgendwo außerhalb klicken oder Esc drücken.
  • Tastatur- / Maus-Tab: In der Spalte Modus gibt es pro Zeile drei farbige Kreise — C, M, S. Klick auf einen Kreis schaltet den jeweiligen Modus an oder aus (aktiv = leuchtend und leicht vergrößert).
  • Filter-Bar (unter den Tabs): Klick auf ● Combat, ● Mining oder ● Salvage blendet alle Felder, die nicht diesen Modus haben, stark aus. Mehrere Modi können gleichzeitig aktiv sein (ein Feld reicht, wenn es einen der aktiven Modi trägt). Alle hebt den Filter wieder auf.
  • Ein Feld kann mehrere Modi gleichzeitig tragen — z. B. ein Button, der sowohl im Combat- als auch im Mining-Modus genutzt wird.
  • Zeilen-Tags: Wenn ein Feld mehrere Zeilen enthält, kann jede Zeile einen eigenen Modus bekommen. Im Tab 📋 Liste erscheint pro Zeile eine eigene Reihe mit C M S-Buttons — einfach direkt klicken. Auf dem Stick-Overlay zeigt ein schmaler Farb-Streifen links vom Feld die gesetzten Zeilen-Tags als stille Anzeige.

Star Citizen Import

  • Auf ⬇ SC Import klicken und die eigene actionmaps.xml aus Star Citizen auswählen.
  • Die Datei liegt bei LIVE normalerweise unter:
    E:\Programme\Roberts Space Industries\StarCitizen\LIVE\user\client\0\controls\mappings
  • Die Datei liegt bei HOTFIX normalerweise unter:
    E:\Programme\Roberts Space Industries\StarCitizen\HOTFIX\user\client\0\controls\mappings
  • Joystick L und R werden automatisch erkannt (LEFT / RIGHT im Gerätenamen).
  • Schaltflächen und Achsen werden importiert.
  • Gesperrte Felder werden beim Import übersprungen.

Star Citizen Mapping-Dateien finden

  • Eigene Mappings im Spiel mit pp_rebindkeys export Name exportieren.
  • Wichtig: Auf den aktuell gespielten Kanal achten. Wer HOTFIX spielt, muss im HOTFIX-Ordner suchen; wer LIVE spielt, im LIVE-Ordner.
  • LIVE:
    E:\Programme\Roberts Space Industries\StarCitizen\LIVE\user\client\0\controls\mappings
  • HOTFIX:
    E:\Programme\Roberts Space Industries\StarCitizen\HOTFIX\user\client\0\controls\mappings

Drucken

  • Klick auf 🖨 Drucken im Header öffnet den Browser-Druckdialog.
  • Jede Stick-Seite (z. B. Alpha L, Alpha R) erscheint als eigene Druckseite — die Vorlage mit allen eingetragenen Belegungen darauf.
  • Tastatur und Maus kommen gemeinsam auf eine Seite als sortierte Tabelle.
  • Format (A4, A3, Hoch- oder Querformat) wird im Browser-Druckdialog gewählt.
  • Leere Felder werden im Ausdruck ausgeblendet.

Profile

  • Die Profil-Leiste direkt unter dem Header zeigt alle gespeicherten Profile als Chips an.
  • Klick auf einen Chip wechselt das aktive Profil — alle Felder, Tags und der Changelog werden sofort neu geladen.
  • + Neu legt ein neues, leeres Profil an (Name wird abgefragt).
  • Doppelklick auf einen Profil-Namen öffnet ein Eingabefeld zum Umbenennen. Enter oder Klick außerhalb speichert.
  • Das ✕ am Chip löscht das Profil nach Bestätigung. Das Profil Standard kann nicht gelöscht werden.

Buttons im Header

  • ⬇ SC Import — lädt eine Star-Citizen-XML-Datei und übernimmt erkannte Belegungen.
  • ↶ Rückgängig — macht die letzte Änderung rückgängig.
  • ↺ Reset — leert alle nicht gesperrten Felder (nach Bestätigung).

Tabs

  • Alpha L / Alpha R — linker und rechter Stick der Virpil-Vorlage.
  • Tastatur / Maus — Tabellenansicht für importierte Tastatur- und Mausbelegungen.
  • Changelog — zeigt wann welches Feld zuletzt geändert wurde.
  • ? Hilfe — diese Seite.

Hinweise

  • Die Daten werden im Browser-Speicher (localStorage) abgelegt — sie bleiben solange erhalten, bis der Browser-Cache geleert wird.
  • Jeder Browser speichert seine eigenen Daten — beim Wechsel des Browsers gehen die Einträge nicht automatisch über.
